# Ludo Game (Python)

A console-based Ludo game for 2–4 players implemented in Python.

## How to Play
- Each player rolls a dice in their turn.  
- Tokens start moving only after rolling a 6.  
- Move tokens around the board according to dice rolls.  
- Capture opponent tokens by landing on their position.  
- First player to move all tokens to the home area wins.
